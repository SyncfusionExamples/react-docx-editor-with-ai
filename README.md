# React DocX AI Editor Sample

A learning sample demonstrating how to securely integrate **Syncfusion DocX Editor (React)** with **Azure OpenAI** using an **ASP.NET Core Web API**.

Unlike the original React sample, this project does **not expose Azure OpenAI credentials to the browser**. All Azure AI communication is performed through a secure ASP.NET Core backend.

---

# Solution Structure

```text
DocX.React.AI
    React application containing the Syncfusion DocX Editor.

DocX.DocumentAI.Server
    ASP.NET Core Web API responsible for processing AI requests
    and securely communicating with Azure OpenAI.

start.ps1
    Starts both the React application and ASP.NET Core Web API.
```

---

# Architecture

```text
+-----------------------+
|   DocX.React.AI       |
|  (React Application)  |
+-----------+-----------+
            |
            | POST /api/document-ai/process
            |
            ▼
+-------------------------------+
| DocX.DocumentAI.Server        |
| ASP.NET Core Web API          |
+---------------+---------------+
                |
                |
                ▼
+-------------------------------+
| Azure OpenAI                  |
| Chat Completion API           |
+-------------------------------+
```

The React application builds the AI prompt and conversation messages.

The ASP.NET Core Web API:

- Receives AI requests
- Validates the request
- Calls Azure OpenAI
- Returns the generated response

The Azure OpenAI API Key is **never exposed to the browser**.

# Azure OpenAI Configuration

Before running the sample, configure your Azure OpenAI settings.

Open:

```text
DocX.DocumentAI.Server/appsettings.json
```

Update the following section.

```json
"AzureOpenAI": {

  "Endpoint": "https://YOUR_RESOURCE_NAME.openai.azure.com/",

  "ApiKey": "YOUR_API_KEY",

  "DeploymentName": "YOUR_DEPLOYMENT_NAME"

}
```

Replace:

| Setting | Description |
|----------|-------------|
| Endpoint | Azure OpenAI Endpoint |
| ApiKey | Azure OpenAI API Key |
| DeploymentName | Azure OpenAI Deployment Name |

> **Important**
>
> Every developer must provide their own Azure OpenAI configuration.
>
> The repository does **not** contain valid Azure credentials.

# API Endpoint

The React application communicates with a single endpoint.

```http
POST /api/document-ai/process
```

The request contains the AI conversation generated by the React application.

Example:

```json
{
  "messages": [
    {
      "role": "system",
      "content": "You are a helpful assistant."
    },
    {
      "role": "user",
      "content": "Write an appointment letter."
    }
  ]
}
```

The response:

```json
{
  "text": "<generated content>"
}
```

---

# Why a Single Endpoint?

The original Syncfusion React sample already builds AI prompts for all supported operations.

Examples:

- Generate
- Rewrite
- Grammar
- Translate
- Summarize

Instead of creating separate Web API endpoints for each feature, the complete conversation is forwarded to the server.

Benefits:

- No duplicated prompt logic
- Cleaner architecture
- Easier maintenance
- Secure Azure integration
- Future AI providers can be integrated without changing the React application

---

# Security

This sample intentionally moves all Azure AI communication to the server.

The browser never receives:

- Azure Endpoint
- Azure API Key
- Deployment Information

Only the ASP.NET Core Web API communicates with Azure OpenAI.
